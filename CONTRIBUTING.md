# Contributing to objcpp

#### General guidelines

- Submitting PRs
  - I would highly appreciate if you will open an issue 1st, before opening a PR
  - Include a LICENSE notice for any PR that contains copyrighted code from external sources
- AI Slop
  - Do not submit vibe coded PRs
  - Any use of integrated AI tools/agents such as Cursor, Copilot etc. is strictly prohibited
